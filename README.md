# HTF · Homework Time Forty ⏱️

아이들이 40분 동안 숙제를 하고, 하나씩 **클리어 → 셀카로 결과물 촬영 → Gemini 가 성의 판독**까지 하는 태블릿용 웹 대시보드입니다.

## 흐름

1. **로그인** — 아이 이름 선택(박준선 / 박준혁). 처음이면 생년월일·학교·학년/반을 적고, **나를 닮은 캐릭터를 꾸미고**(친구 12종·색 8종·모자/안경 등 10종, 랜덤 버튼), 비밀번호(숫자 4자리)를 정합니다. 이후엔 비밀번호만 누르면 됩니다. 캐릭터는 로그인 화면·상단 바·숙제 화면에 계속 나옵니다.
2. **오늘의 Homework** — 숙제를 적습니다. 지난 HTF 에서 못 끝낸 숙제는 `🔁 이어하기` 표시와 함께 자동으로 들어 있습니다. 같은 이름으로 2번 이상 적은 숙제는 `⭐ 자주 하는 숙제` 단축 버튼(최대 8개)으로 나타나, 누르면 바로 들어갑니다. 이미 목록에 있는 숙제는 버튼에서 빠집니다.
3. **시계 · 준비 화면** — 아날로그/디지털 시계와 준비 멘트, 시간 설정(기본 40분, ±5분 또는 직접 입력). 시작을 누르면 `3·2·1·GO!` 뒤 타이머가 시작됩니다.
4. **HTF 진행** — 줄어드는 링 타이머, 로켓 진행 바, 절반/10분/5분/1분 남음 알림, 마지막 10초 카운트. 화장실 등으로 **⏸️ 잠깐 멈춤**을 누르면 타이머가 멈추고(한 번의 HTF 에서 합쳐 10분까지, `MAX_PAUSE_MIN`), 다녀와서 ▶️ 를 누르면 이어집니다. 멈춘 채 새로 고침해도 그대로예요. 쉬는 시간을 다 쓰면 자동으로 다시 흐릅니다.
5. **클리어** — 셀카 카메라가 열립니다. 숙제(종이 등)가 보이거나 **2초가 지나면 3·2·1 뒤 자동 촬영**합니다. 결과물이 없으면 얼굴이나 V 포즈를 취하라는 안내가 나옵니다. 찍은 뒤 `다시 찍기 / 이 사진으로 클리어`를 고릅니다.
6. **AI 판독** — 사진, 숙제 이름, 아이의 나이·학년/반을 Gemini 에 보내 `성의 있음 / 보통 / 성의 부족 / 확인 불가` 와 별점, 아이용 한마디, 부모님용 메모를 저장합니다.
7. **종료** — 시간이 끝나거나 모두 클리어하면 결과 화면. 못 끝낸 숙제는 다음 HTF 로 이월됩니다. **숙제를 모두 클리어하면 보상으로 🌈 마음 쉼터**가 열립니다.
8. **마이페이지** — 정보·비밀번호·기본 시간 수정, 캐릭터 다시 꾸미기, 숙제 기록(사진·AI 결과) 보기.
9. **부모님 메뉴** — 로그인 화면 아래 `👪 부모님 메뉴`. 테스트한 기록을 지우거나 비밀번호를 잊은 친구를 도울 때 씁니다. 환경변수 `ADMIN_CODE` 가 있어야 켜집니다.

새로 고침하거나 다시 로그인해도 진행 중인 HTF 는 서버 시각 기준으로 이어집니다.

## 🌈 마음 쉼터 (3D 교실 투어)

숙제를 모두 클리어한 아이를 위한 보상입니다. 노란 후드에 검정 바지를 입은 제페토 같은 캐릭터(이름표에 내가 고른 동물)로 **교실을 5분 동안** 천천히 걸으며 눈과 마음을 쉽니다. 교실은 **매원초등학교 교실**을 본떠 만들었어요: 하얀 칠판·TV·알림판·시계가 있는 앞벽, 블라인드가 내려온 창문과 나무 수납장, 책상마다 달린 투명 칸막이와 초록색 의자, 책가방, 사물함과 책장, 하얀 타일 바닥과 형광등 천장. 창가의 햇빛, 천장에 매단 종이별, 잔잔한 배경음이 있어요. (소리는 모두 브라우저에서 만들어 파일이 없습니다. 오른쪽 위 🔊로 끌 수 있어요.)

- **캐릭터**: 큰 눈이 깜빡이고(손을 흔들 때는 활짝 웃어요) 볼터치, 윤기 나는 머리카락, 후드·카디건·스니커즈가 있는 3등신 아바타예요. 선생님은 카디건과 목걸이 명찰, 친구는 후드·티셔츠·줄무늬 옷에 가방을 메고 있어요.
- **조작**: 왼쪽 조이스틱으로 걷기 · 화면 드래그로 시점 돌리기 · (키보드) WASD/방향키, Q/E 회전
- **마음 별 7개**: 창가에서 먼 곳 20초 보기 👀 · 러그에서 숨 3번 쉬기 🌬️ · 칠판에 "고마워/괜찮아/잘했어" 쓰기 ✏️ · 토끼 곁에 가만히 있기 🐰 · 선생님·친구 3명에게 인사하기. 화면 위 안내 화살표가 다음 목적지를 알려 줍니다.
- **선생님과 친구들은 스스로 돌아다녀요**: 책상 사이로 길을 찾아 걷고(가구를 피해 돌아가요), 창가·책장·칠판을 구경하고, 의자나 쿠션에 앉고, 서로 마주 보고 이야기하고, 선생님은 책상 통로를 돌아보며 칠판에 글씨를 씁니다. 가까이 가면 멈춰서 손을 흔들며 한마디를 해요.
- **보상**: 모은 별은 서버에 저장되어 마이페이지에 "마음 쉼터 N번 · 마음 별 M개"로 쌓입니다 (한 번의 올 클리어에 한 번만 저장). 3D 를 쓸 수 없는 기기에서는 1분짜리 눈 쉬기로 대신해요.
- **교실의 선생님·친구는 아이마다 따로**입니다. 기본값은 준선: 서은미 선생님 · Ms. Kimpsey 선생님, 준혁: 곽하영 선생님 · Mr. Oullete 선생님 (모습은 임의로 그린 것이라 실제와 다르면 고치세요).
- **형제의 교실은 따로** 있고 분위기도 달라요 (`server/rooms.js`). 형 박준선은 **5학년 국화 반** (노랑·하양, 국화 화분과 창가 화단, 칠판 위 "매원초등학교 5학년 국화 반" 문패), 동생 박준혁은 **1학년 난초 반** (보라·분홍, 난초 화분, 아이와 친구들이 조금 더 작아요). 학교·반 이름을 바꾸려면 `server/rooms.js` 의 `ROOMS` 를 고치세요 (`school` 이 비어 있으면 문패에 반 이름만 나와요).
- **엄마·아빠 캐릭터로 같이 들어가기**: 부모님 메뉴 → 아이 카드의 **👪 교실에 같이 들어가기**에서 👩 엄마 / 👨 아빠를 골라 그 아이의 교실에 들어갑니다 (미션·시간 제한 없이 자유롭게 걸어요). 아이가 그때 쉼터에 있으면 서로 걷는 모습이 보이고, 부모님은 💛 오늘도 수고했어 · ❤️ 사랑해 · 👏 정말 잘했어 · 🤗 이리 와 한마디를 말풍선으로 전할 수 있어요. 아이가 엄마·아빠에게 다가가 인사해도 마음 별 인사로 세어집니다. 위치는 서버 메모리에만 잠깐(몇 초) 두며 저장하지 않아요 (서버가 하나일 때 쓰는 가벼운 방식). 선생님·친구들은 각 화면에서 따로 돌아다닙니다.
- 부모님 메뉴 → 아이 카드의 **🏫 교실 친구·선생님**에서 **만들고 고치고 지우고**(최대 12명), **🌈 이 교실 미리 보기**로 아이가 보게 될 모습을 먼저 둘러볼 수 있어요. 이름, 친구/선생님, 아이를 만나면 하는 말(`{이름}` 은 아이 이름으로 바뀜), 머리 모양(6종)·머리색·피부색·상의색·바지/치마·안경을 3D 미리보기를 보며 고릅니다.

## 📖 한문 6급 (하루 5자 × 60일)

손을 다쳐 종이 숙제를 못 할 때도 할 수 있는, 태블릿 한자 수업입니다. 한국어문회 **6급 배정한자 300자**(8급 50 · 7급Ⅱ 50 · 7급 50 · 6급Ⅱ 75 · 6급 75)를 하루 5자씩 60일에 나눠 익힙니다. 한 날의 5자는 뜻이 이어지는 것끼리 묶었어요 (예: 一二三四五, 日月火水木, 東西南北中).

- **입구는 "오늘의 Homework" 화면 맨 위** 카드입니다. `➕ 숙제에 넣기`를 누르면 `📖 한문 6급 · 오늘의 5자`가 숙제 목록에 들어가고, HTF 타이머가 돌아갈 때 그 숙제의 `📖 공부하기` 버튼으로 수업을 열어요. 수업을 마치면 카메라 없이 **CLEAR** 가 되고(다른 숙제와 똑같이 올 클리어·마음 쉼터 보상에 세어집니다), 타이머 전에 `✏️ 지금 해볼래요`로 미리 해도 돼요. 처음에는 어디서부터 시작할지(8급 / 7급Ⅱ / 7급 / 6급Ⅱ / 6급 새 한자) 고릅니다.
- **수업 한 번(약 20분)**: 🔥 몸풀기(지난번에 배운 글자 퀴즈, 배운 적이 있을 때만) → 글자마다 ① **보기**(획순 애니메이션, 부수는 주황색, 외우는 요령, 낱말 예시, 읽어 주기) → ② **따라쓰기**(연한 글자를 손가락·펜으로 획순대로) → ③ **혼자 쓰기**(보지 않고) → ❓ 마무리 퀴즈(한자→뜻·소리, 뜻·소리→한자) → 별점과 기록 저장. 막히면 💡힌트, 어려운 글자는 실수 2번(또는 20초) 뒤에 건너뛸 수 있고, 한 획을 여러 번 틀리면 알아서 다음 획으로 넘어가요.
- **하루에 한 번만** 진도가 나가요 (한국 시간 기준). 같은 날 한 번 더 하면 복습으로 열리고 진도는 그대로입니다. 마이페이지의 `📖 한문` 탭에서 배운 글자를 눌러 한 글자씩 다시 연습하거나, 배운 날을 골라 복습 수업을 할 수 있어요 (시작 단계에서 건너뛴 날은 "배운 글자"로 세지 않습니다).
- **부모님 메뉴 → 아이 카드의 `📖 한문 설정`**: 켜기/끄기, 이 단계부터 시작, 하루 앞뒤로 옮기기, 오늘 몫 다시 열기, 최근 수업 기록(별점·실수 횟수). 기본으로는 박준선만 켜져 있고 환경변수 `HANJA_KIDS` 로 바꿀 수 있어요.
- **자료**: 글자·급수·훈음·부수·획수는 한국어문회 배정한자 자료를, 획순과 따라쓰기는 [Hanzi Writer](https://hanziwriter.org/)(MIT)와 `hanzi-writer-data`(Make Me a Hanzi 기반, Arphic Public License)를 npm 패키지로 씁니다. 외우는 요령과 낱말 예시는 직접 쓴 것으로 글자의 유래 설명이 아니라 외우기 위한 놀이예요. 패키지에 없는 시험용 정자 4자(敎 飮 窓 淸)는 비슷한 글자의 획에 부품 글자를 합쳐 만든 근사 데이터(`public/data/strokes`)를 쓰므로 획 모양이 글꼴과 아주 조금 다를 수 있습니다.
- **글자·요령을 고치려면** `scripts/hanja/notes-*.txt` 를 고치고 `node scripts/hanja/build.js` 를 실행하세요 (300자가 빠짐없이 한 번씩 들어갔는지, 낱말에 그 글자가 있는지, 독음 글자 수가 맞는지 검사하고 `public/data/hanja6.json` 을 만듭니다).

### 부모님 메뉴 (숙제 편집·초기화)

`ADMIN_CODE` 를 정하고(Render → Environment) 로그인 화면의 `👪 부모님 메뉴`에 그 코드를 입력합니다.

**📝 숙제 보기·편집** — 아이가 빼먹은 숙제를 넣어 줄 수 있습니다.
- 아직 안 한 숙제는 추가·이름 고치기(✏️)·지우기(🗑️)가 되고, 바로 아이 화면에 반영됩니다. 아이가 자주 하는 숙제는 버튼으로 한 번에 넣을 수 있습니다.
- 부모님이 넣은 숙제에는 아이 화면에서 `👪 부모님이 넣어 줬어요` 표시가 붙습니다.
- 클리어한 숙제(최근 30개)는 날짜별로 **찍은 사진 썸네일**과 AI 판독 결과가 나오고, 눌러서 사진을 크게 볼 수 있습니다(AI가 본 것: 숙제/얼굴/V 포즈, 별점, 아이용 한마디, 부모님용 메모). 보기만 가능합니다.
- 아이가 이미 HTF 화면을 열어 둔 상태라면 새로 고쳐야 보입니다. 숙제는 한 아이당 30개까지입니다.

아래 세 버튼은 지우는 동작이라 확인 창을 거칩니다.

| 버튼 | 지워지는 것 | 남는 것 |
|---|---|---|
| 🧹 기록만 지우기 | 숙제·사진·AI 판독·HTF 기록 | 프로필·캐릭터·비밀번호 |
| 🔑 비밀번호 다시 정하기 | 비밀번호 | 기록·프로필·캐릭터 (다음 로그인 때 새로 정함) |
| 🔄 처음부터 다시 | 위의 모든 것 | 없음 (다시 "처음이에요" 상태) |

코드를 5번 틀리면 1분간 잠기고, 메뉴에 들어온 뒤 30분이 지나면 다시 입력해야 합니다.

## 로컬 실행

Node 22.9 이상이 필요합니다.

```bash
npm install
npm run dev
```

`http://localhost:3000` 에서 열립니다. `DATABASE_URL` 이 없으면 로컬 임시 DB(PGlite, `./data`)를 씁니다. AI 판독을 켜려면 `.env.example` 을 `.env` 로 복사해 `GEMINI_API_KEY` 를 채우세요. 카메라는 `localhost` 또는 HTTPS 에서만 동작합니다.

## Render 무료 플랜에 올리기

Render 무료 웹 서비스는 **디스크가 임시**(재시작·재배포 때 사라짐)라서, 기록을 보관하려면 외부 Postgres 가 필요합니다.

1. **무료 Postgres 만들기** — 추천은 [Neon](https://neon.tech) 입니다. 프로젝트를 만들고 Connection string(`postgresql://…?sslmode=require`)을 복사하세요. (Render 자체 무료 Postgres 는 생성 후 일정 기간이 지나면 만료되고, Supabase 무료는 일정 기간 접속이 없으면 일시중지될 수 있어 주말에만 쓰는 용도엔 Neon 이 편합니다. 무료 정책은 바뀔 수 있으니 가입 시 확인하세요. Supabase 를 쓴다면 Render 가 IPv4 라서 *직접 연결*이 아니라 **pooler 주소**를 써야 합니다.)
2. **Gemini API 키** — [Google AI Studio](https://aistudio.google.com/apikey) 에서 발급합니다.
3. **GitHub 에 올리기** — 이 폴더를 저장소로 push 합니다. (`.gitignore` 가 `node_modules`, `data`, `.env` 를 제외합니다.)
4. **Render 에서** `New → Blueprint` 로 저장소를 고르면 `render.yaml` 대로 서비스가 만들어집니다. (직접 만들 땐 `Web Service`, Build `npm install --omit=optional`, Start `npm start`, Plan `Free`.)
5. **환경변수 입력** — `DATABASE_URL`, `GEMINI_API_KEY`.
6. 배포가 끝나면 주소(`https://….onrender.com`)를 태블릿에서 열고, **두 아이의 첫 등록을 바로 마치세요.** (등록 전 이름은 주소를 아는 누구나 선점할 수 있습니다.)

### 환경변수

| 이름 | 설명 |
|---|---|
| `DATABASE_URL` | Postgres 접속 주소 (운영 필수) |
| `GEMINI_API_KEY` | 없으면 AI 판독 없이 사진만 저장 |
| `GEMINI_MODEL` | 기본 `gemini-3.5-flash-lite` (저렴한 Flash-Lite 계열, 요금 문서 기준 무료 등급 있음) |
| `GEMINI_FALLBACK_MODELS` | 기본 모델이 404/429/장애일 때 차례로 시도 (기본 `gemini-3.1-flash-lite,gemini-2.5-flash-lite`). 키 오류(401)·결제 문제(402)는 바로 멈춥니다 |
| `KIDS` | 로그인 화면 이름들 (기본 `박준선,박준혁`) |
| `ADMIN_CODE` | 부모님 메뉴 비밀번호. 비워 두면 부모님 메뉴가 꺼집니다 |
| `HANJA_KIDS` | 한문 6급 과정을 기본으로 켜 둘 아이 이름들 (기본 `박준선`). 부모님 메뉴에서 아이마다 따로 켜고 끌 수 있어요 |
| `MAX_PAUSE_MIN` | 한 번의 HTF 에서 "잠깐 멈춤"으로 쓸 수 있는 시간(분). 기본 `10` |
| `SESSION_SECRET` | 로그인 토큰 서명 키 (Blueprint 가 자동 생성) |

### 주말에만 쓸 때 알아둘 점

- 15분쯤 안 쓰면 서버가 잠들고, 다시 열면 **깨어나는 데 30초~1분** 걸립니다. 화면에 "깨우는 중" 안내가 나오고 자동으로 재시도합니다. HTF 시작 몇 분 전에 미리 열어 두면 편합니다.
- 숙제 사진은 DB 에 압축(JPEG) 상태로 저장됩니다. 로그인한 본인만 볼 수 있습니다.
- Gemini 로는 **사진, 숙제 이름, 나이, 학년/반**만 보냅니다 (이름·학교명·생년월일은 보내지 않음). 무료 등급은 입력 데이터가 Google 제품 개선에 쓰일 수 있으니 아이 사진이 걱정되면 유료 등급 키를 쓰세요.
- AI 분석이 실패해도 클리어와 사진은 저장되고, 마이페이지 기록에서 `🔄 AI 다시 보기`로 다시 요청할 수 있습니다.

### 물체 감지 튜닝

`public/js/camera.js` 상단의 `CFG` 에서 조절합니다. 감지는 AI 가 아니라 가벼운 화면 비교입니다 — 처음 장면보다 **밝고 색이 옅은 영역(종이)이 화면의 8% 이상 새로 나타나거나**, 화면의 절반 이상이 확 바뀌면 "숙제가 보인다"고 판단합니다. 놓쳐도 2초 뒤에는 어차피 촬영하고, 촬영 후 `다시 찍기`가 있습니다. 오작동이 잦으면 `newPaperRatio` 를 올리세요.
